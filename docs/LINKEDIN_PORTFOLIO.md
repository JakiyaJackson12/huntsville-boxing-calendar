# LinkedIn + Portfolio Copy

## LinkedIn project title
**Huntsville Boxing Club Digital Calendar**

## LinkedIn description
Built a full-stack, touch-friendly digital scheduling dashboard for Huntsville Boxing Club using HTML, CSS, vanilla JavaScript, Node.js, and Express. Designed the interface directly from client feedback for a large interactive gym display, with Week/Day/Month calendar views, Today's Agenda, Upcoming Events, LIVE NOW / UP NEXT status, automatic refresh, offline fallback caching, and a Google Calendar integration layer that keeps credentials server-side.

The current public demo uses realistic sample data while production Calendar integration and gym-board deployment are completed.

**Tech:** JavaScript, HTML, CSS, Node.js, Express, Google Calendar API, REST/JSON, service workers, automated tests

## Portfolio short version
A client-directed digital scheduling system for a local boxing gym. The application combines a touch-first dark sports interface with a Node/Express backend, live schedule rendering, automatic refresh, offline fallback, and a secure Google Calendar integration architecture. Built for eventual kiosk deployment on the gym's interactive wall display.

## Resume-style bullets
- Built a full-stack digital scheduling dashboard for a local boxing gym using **JavaScript, HTML/CSS, Node.js, and Express**, translating direct client feedback into Week/Day/Month calendar views and a touch-first large-display UI.
- Designed a server-side **Google Calendar API** integration that normalizes schedule data while keeping credentials out of the browser, with demo-data isolation for safe public development and presentation.
- Improved kiosk reliability with **automatic refresh, last-known schedule fallback, stale-data warnings, service-worker app-shell caching, security headers, bounded API queries, and automated tests**.
